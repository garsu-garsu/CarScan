# CarScan 백업 파일 형식 (`carscan-backup`, version 1)

사용자 암호로 암호화된 단일 파일. 확장자는 `.backup`, MIME은 `application/octet-stream`.
`:core:data`의 `backup` 패키지가 읽고 쓴다 — `BackupFormat.kt`가 이 문서의 정본이다.

## 왜 기기 키가 아니라 사용자 암호인가

`docs/STATUS.md`의 결정: **기기 저장 키로 암호화하면 폰을 바꿨을 때 복호화가 불가능해져 백업의
목적이 무너진다.** 그래서 키는 항상 사용자가 입력한 암호에서 유도한다. 앱도, 우리도 파일을 열
수 없다 — 암호를 잊으면 그 파일은 끝이다. 암호 입력 화면이 그 사실을 그대로 말한다.

## 바이트 배치

```
<header line>\n                 ← 평문 UTF-8 JSON, 한 줄, 개행으로 끝남
<frame> <frame> ... <frame>     ← EOF까지 반복
```

한 프레임:

```
[4바이트 big-endian 길이][암호문 + 16바이트 GCM 태그]
```

- **암호**: AES-256-GCM, 태그 128비트.
- **nonce**: 12바이트 = 0으로 채운 4바이트 + 프레임 번호(0부터) big-endian 8바이트.
  카운터 nonce가 안전한 이유는 **파일마다 salt가 새로 뽑혀 키가 1회용**이기 때문이다.
- **AAD**: 개행을 포함한 헤더 줄 전체. 그래서 헤더는 평문이지만 **위조는 불가능**하다 —
  iteration 수를 1로 낮춰 적어 넣으면 첫 프레임 인증이 깨진다.
- 프레임 평문 = 레코드 하나의 UTF-8 JSON.

### 헤더

```json
{"format":"carscan-backup","version":1,"kdf":"PBKDF2WithHmacSHA256",
 "iterations":210000,"salt":"<base64 16바이트>","cipher":"AES-256-GCM"}
```

평문일 수밖에 없다 — `salt`와 `iterations`가 있어야 키를 유도할 수 있기 때문이다.
`version`은 **1일차부터** 있다. 읽는 쪽은 자기 버전 이하면 읽고, 더 높으면
`UNSUPPORTED_VERSION`으로 거절한다. 사용자의 주행 기록을 추측으로 다루지 않는다.

### 키 유도

**PBKDF2-HMAC-SHA256, 210,000 라운드, 256비트.** 암호의 단순 해시가 아니라 KDF다: 백업 파일은
오프라인에서 공격자 하드웨어 속도만큼 시도할 수 있으므로 작업량 자체가 방어다. 210,000은 OWASP
2023 권고치이고, 파일 안에 적혀 있으므로 나중에 올려도 옛 파일은 그대로 읽힌다.

Argon2id가 GPU에 더 강하지만 KMP에서는 전부 서드파티 의존성이다. PBKDF2와 AES-GCM은
**Android(minSdk 26)와 iOS가 기본으로 들고 있는 것** 중 가장 강한 조합이고, 그래서 암호
라이브러리를 하나도 추가하지 않았다. 직접 만든 암호는 하나도 없다 — `BackupCrypto.kt`의
`expect`/`actual` 네 개는 플랫폼 API를 그대로 부르는 얇은 어댑터다.

## 레코드

판별자는 `"type"`이 아니라 **`"record"`** 다. `TripEventRecord`에 이미 `type` 컬럼
(`HARSH_BRAKE` 등)이 있어 충돌하기 때문이다.

기록되는 순서 — 되돌릴 때 외래 키가 성립해야 하므로 순서가 계약의 일부다:

| # | `record` | 내용 |
|---|---|---|
| 1 | `settings` | 사용자 설정 전체 (단위, 테마, 게이지, 자동 연결 등) |
| 2 | `bookmarks` | 즐겨찾기한 신호 (`M:`/`S:` 토큰, DataStore에 저장된 그대로) |
| 3 | `vehicle` | 차량 한 대 |
| 4 | `layout` | 대시보드 배치 (`layout_json`은 불투명 문자열) |
| 5 | `dtc` | 고장 코드 이력 (해제된 것 포함) |
| 6 | `trip` | 주행 요약 한 건 |
| 7 | `series` | 그 주행의 1Hz 신호 청크 하나 |
| 8 | `gps` | 그 주행의 경로 청크 하나 |
| 9 | `event` | 그 주행의 급가속·급제동 마커 하나 |

6~9는 주행마다 반복된다. 차량은 언제나 그 차량을 가리키는 주행·배치·고장코드보다 먼저 나온다.

`series`/`gps`의 배열은 **DB에 있는 BLOB을 그대로** base64로 옮긴다 — 리틀엔디언 IEEE-754,
초당 한 값, 차가 답하지 않은 초는 NaN. 청크 통계(`minV`/`maxV`/`avgV`)도 다시 계산하지 않고
그대로 옮긴다. 복원한 주행의 통계가 원본과 조금이라도 다르면, 이미 끝난 주행에 대해 조용히
거짓말을 하는 셈이기 때문이다. base64는 원본 대비 약 1/3의 용량을 더 쓴다 — 레코드 하나가
그대로 JSON 문서 하나가 되는 단순함과 맞바꾼 값이다.

## 일부러 넣지 않은 것

- **`adapter`** — 학습한 BLE 특성(GATT UUID, 쓰기 청크 크기, STN 여부)은 *그 기기 + 그
  스캐너* 조합의 성질이다. 다른 폰에 옮겨 심으면 첫 연결이 잘못된 값으로 시작한다. 두 번째
  연결이면 어차피 다시 학습한다.
- **`signalset`** — OBDb 캐시. 용량이 크고 언제든 다시 내려받을 수 있으며, CC BY-SA 데이터를
  사용자 파일에 복제해 퍼뜨릴 이유가 없다.
- **`command_support`** — "이 차가 이 명령에 답하는가"의 캐시. 다시 알아내는 데 몇 초면 되고,
  낡은 결과를 믿는 쪽이 오히려 위험하다.
- **구매/프리미엄 상태** — Google Play 계정에 있고, 파일로 옮길 수 있으면 안 된다.

## 되돌리기가 보장하는 것

- **지우지 않는다.** 모든 쓰기가 행의 UUID를 키로 한 삽입이다. 이미 주행 기록이 있는 폰에
  복원하면 둘 다 남는다.
- **두 번 넣어도 하나다.** 같은 파일을 두 번 복원해도 아무것도 늘어나지 않는다. 트립·차량·
  대시보드 ID가 UUID인 이유가 이것이다 (`docs/STATUS.md`).
- **같은 차는 한 대다.** VIN은 유일 인덱스라, 이 폰에 이미 같은 VIN의 차가 다른 UUID로 있으면
  백업 쪽 ID를 로컬 ID로 바꿔치기해서 주행·배치·고장코드를 그 차에 붙인다. 이 처리가 없으면
  외래 키 위반으로 복원 전체가 실패한다.
- **이미 있는 행이 이긴다.** 차량 이름이나 대시보드 배치를 이 폰에서 바꿔 뒀다면 그대로 둔다.
  설정만은 덮어쓴다 — 설정을 되돌린다는 말의 뜻이 그것이다.
- **전체를 한 트랜잭션으로 감싸지 않는다.** 수십 MB짜리 복원을 한 트랜잭션에 넣으면 WAL이
  파일 크기만큼 커지는데, 얻는 것이 없다. 모든 쓰기가 추가적이고 멱등이라 중간에 끊겨도
  망가진 것은 없고, 다시 실행하면 이어서 끝난다.

## 메모리

내보내기는 **주행 전체를 절대 메모리에 올리지 않는다.** `selectChunkKeys`/`selectChunkIndexes`
가 BLOB을 건드리지 않고 청크 목록만 읽어오고, 그 다음 한 번에 한 청크씩 읽어 바로 한 프레임으로
암호화해 파일로 흘려보낸다. 최대 사용량은 청크 하나 — 10분치, 수십 KB — 로, 주행이 10시간이든
같다. 되돌리기도 대칭이다: 프레임 하나를 읽어 한 행을 쓰고 버린다.

## 버전을 올려야 할 때

- 레코드에 **필드를 추가**하는 것 → 올리지 않는다. 읽는 쪽이 `ignoreUnknownKeys`다.
- **레코드 종류를 추가**하는 것 → 올리지 않는다. 모르는 레코드는 건너뛴다.
- 필드의 **의미·단위·인코딩을 바꾸거나** 프레임/헤더 구조를 바꾸는 것 → 올린다.

## 미구현

**iOS.** `BackupCrypto.ios.kt`의 네 함수는 `TODO()`이고, `BackupLauncher.ios.kt`는 파일 선택을
열지 않는다. Apple 타깃은 macOS 호스트에서만 등록되므로 이 저장소에서는 한 번도 컴파일된 적이
없다. 대충 동작하는 척하는 스텁을 두면 **영영 복호화할 수 없는 백업 파일**을 사용자에게 쥐여
주게 되므로, 첫 호출에서 바로 죽게 두었다. 실제 구현 경로는 CryptoKit `AES.GCM` +
CommonCrypto `CCKeyDerivationPBKDF`, 파일은 `UIDocumentPickerViewController`다.
